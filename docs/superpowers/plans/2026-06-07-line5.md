**Task-1 decisions (verified against the codebase):**
- **Decode (OperationDecoder line 5):** `0101 cccc xx mmmrrr`. ss=op[7:6].
  - ss≠3 → ADDQ/SUBQ `0101 ddd q ss mmmrrr`: q=op[8] (0=ADD,1=SUB), ddd=op[11:9] (1-8, 0→8). Immediate = `Mux(ddd===0, 8, ddd)` → IMMQ-style (useImm). Dest = EA op[5:0]: Dn (mode0) → ADD/SUB + NZVCX (size-merged, reuse `writesNzvc`/`writesX`); An (mode1) → full-32 ADD/SUB, NO flags. srcA = dest (read, for ALU `a`), srcB = imm. New OperandKind not needed — set `o.imm`-style via the assembler (the quick imm is opword-derived like IMMQ). To route to An full-32, force **size=LONG** for the An-dest path (ALU `Size.LONG` = full-32, no merge) and clear writesNzvc/writesX. ADDQ #n,An is full-32 regardless of ss — LONG is exactly right (imm 1-8 is positive, no sign issue).
  - ss=3 → Scc / DBcc / TRAPcc by mode:
    - mode 001 → **DBcc** (op[5:3]==001), disp16 follows. cccc=op[11:9... actually op[11:8]].
    - mode≠001 → **Scc**: Dn (mode0) → byte 0xFF/0x00. TRAPcc (mode7 reg2/3/4) out of scope → illegal.
- **cccc field:** for line-5 it is op[11:8] (4 bits). The branch EU's existing 16-condition mux is reused verbatim (cond[3:0]).
- **Scc design:** route to the **branch EU** (it owns the condition mux). The branch EU evaluates `taken(cccc)`; Scc writes Dn[7:0] := taken?0xFF:0x00, preserving upper 24. Reuse the partial-merge idea: read old Dn (psrcA), merge low byte. Add an `isScc` path in the branch EU that drives an int write (reuse the `anWrite`/anW int-write port + BrWbObs.anWrite whitebox channel). No flags.
- **DBcc design (single branch-EU µop):** isBranch + readsNzvc + psrcA=Dn (read) + pdst=Dn (write, writesNzvc=False). New `isDbcc` flag (mirrors `isTrapv`). Branch EU: `condTrue=taken(cccc)`; `decFull = oldDn[31:16] ## (oldDn[15:0]-1)`; write pdst = `Mux(condTrue, oldDn, decFull)` (Dn unchanged if cond TRUE — partial 16-bit dec else); redirect = `!condTrue && (decFull[15:0] != 0xFFFF)`; target=pc+2+disp (relTarget, NOT ibranch). DBRA/DBF = cccc=F (cond=1, taken=False) → always decrements. The int write reuses the anW port (mutually exclusive with the RTS/RTR anWrite ibranch path; DBcc is not ibranch). Whitebox: BrWbObs.anWrite/anData/anArch already maps to an int reg write in the lock-step harness — no harness change.
- **Predecode (PredecodeWord + PredecodeRef, exhaustive-sweep equivalent):** add line-5 (cls 5). ss=op[7:6]; mode=op[5:3]. ss≠3 (ADDQ/SUBQ): dest mode 0/1 (Dn/An) → simple len1; else COMPLEX (mem dest deferred). ss=3: mode001 (DBcc) → simple len2 (opword+disp16); mode0 (Scc Dn) → simple len1; else COMPLEX (mem Scc / TRAPcc deferred). **This frames nextPc correctly (the recurring bug: line 5 currently falls to default → lenWords=0 → nextPc=pc).**
- **Branch-EU registered-boundary rule:** the new DBcc Dn read (tgtRd, already registered into s1TgtBase) + the conditional int write (anW, latency-1) keep the existing registered S0→S1 boundary; no new cross-module combinational crossing.
- **Reuse confirmed:** AluDatapath ADD/SUB + NZVCX (size-merged via `piece(w)`); AluEuPlugin `.B/.W` size-merge for Dn partial writes; BranchEuPlugin 16-cond mux + relTarget (pc+2+disp) + anW int write + BrWbObs whitebox; MicroOpAssembler IMMQ-style quick immediate + isMovea-style An routing.

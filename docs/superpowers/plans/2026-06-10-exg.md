# EXG (exchange two registers) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement **EXG** (`EXG Dx,Dy` / `EXG Ax,Ay` / `EXG Dx,Ay`): exchange the full 32 bits of two registers, setting NO condition codes. Cracked into **3 MOVE µops through int temp T0** (`T0 := Rx ; Rx := Ry ; Ry := T0`).

**Architecture:** NO new `DecOp`, NO new EU datapath, NO new `DecodedUop` field. Pure decode + assemble: `OperationDecoder` does NOT illegalise the line-C EXG opwords; `MicroOpAssembler` matches `isExgOp` on the raw opword and emits the 3-µop crack via the existing `mkUop` helper (mirroring the RTR/RTS/JSR cracks), using `T0` as the swap scratch. `PredecodeWord` frames EXG as `simple, len=1`. Disambiguated from line-C AND/MULU by `line==C && bit8==1 && opword(7:3) ∈ {01000,01001,10001}`.

**Tech Stack:** SpinalHDL 1.14.1 / Scala 2.13 / sbt at `~/sbt/bin/sbt` (NOT on PATH) / Verilator / Vivado 2025.2 (`xcku5p-ffvb676-2-e`, OOC 4 ns). Lock-step vs `m68k040.oracle.Musashi`.

**Working dir:** isolated git worktree on `feat/exg` off current `master` (`c898892`). Run `sbt`/`vivado` from the worktree root.

**Discipline (HARD):** `sbt` not on PATH → `~/sbt/bin/sbt`. NEVER run Verilator+Vivado concurrently. NEVER the whole `ExecuteLockStepSpec` (OOMs) — `-z` subsets, each its OWN `JAVA_OPTS=-Xmx10g timeout 1000 ~/sbt/bin/sbt …` JVM (never batch fastTest+lockstep+IPC). Before vivado: `pgrep -af vivado`, spare any `030`. **The gate is ≥200 MHz now** (relaxed; the 250 push is deferred — [[synth-gate-every-slice]]).

**Templates to mirror (read these first):** the **RTR 3-µop crack** in `MicroOpAssembler.scala` (`isRtrOp` → `rtrCcr`/`rtrPc`/`rtrBranch`, `out.count := 3`, `uops(0..2)`) + the **`mkUop` helper** (every field assigned once) + the **`bad` exclusion list** (`!isRteOp && !isTrapOp && … && !isRtsBad && !isRtrBad && …`); the **line-C decode** in `OperationDecoder.scala` (the `is(0x8,0x9,0xB,0xC,0xD)` arm — AND `!isRmw`/`isRmw`, MULU, `aluRmwMemBad`); `T0/T1` temps + `AssembledUops`; the **3-µop DecodeStage stash** (`DecodeStage.scala:96-125`, `slot0Is3`/`slot1Is3`/`deferSlot1`); `PredecodeWord.scala` (the `is(8,9,C,D)` arm); a decode-unit-test template (`Line5DecodeSpec.scala` / `SccDecodeSpec.scala`).

- [ ] **Step 1: Confirm the line-C opmode mapping + disambiguation.**
  Verify: EXG `1100 xxx 1 ooooo yyy` with `ooooo ∈ {01000,01001,10001}` lands in
  `opmode(8:6) ∈ {5,6}` (the AND-RMW band) and that the AND-RMW path requires a MEMSIMPLE EA
  (`aluRmwMemBad`), so EXG's reg-direct EA (mode 0/1) currently decodes **illegal**. Confirm
  MULU is opmode 3/7 (no collision) and ABCD is **not implemented** (`grep -rn ABCD src/` →
  no matches today). Confirm the discriminator `opword(7:3) ∈ {01000,01001,10001}` is unique
  within line C + bit8=1.

- [ ] **Step 2: Confirm the RTR 3-µop crack is the exact template.**
  In `MicroOpAssembler.scala`: `isRtrOp` builds `rtrCcr`/`rtrPc`/`rtrBranch` via `mkUop`,
  selects `out.count := 3` + `uops(0):=rtrCcr; uops(1):=rtrPc; uops(2):=rtrBranch`, and
  `isRtrOp` is in the `bad` exclusion list (`… && !isRtsBad && !isRtrBad && …`). EXG mirrors
  this exactly (3 `mkUop` MOVE µops, `count=3`, excluded from `bad`).

- [ ] **Step 3: Confirm `mkUop` MOVE writes no flags + full-32 reg write.**
  `mkUop` defaults `op := MOVE`, `writesNzvc := writesNzvc(param, default False)`,
  `writesX := False`, `isMovea := False`. So a `mkUop(size=LONG, srcBReg=src, srcBValid=True,
  dstReg=dst, dstValid=True)` is a full-32 register MOVE that sets NO flags — exactly EXG's
  need. Confirm the ALU EU's MOVE result = srcB (the MOVE source is the srcB slot) and that
  `writesNzvcIfDataDst` is an `OpSpec`/`opUop`-only path (NOT applied to `mkUop` µops), so an
  EXG move to a Dn does NOT spuriously set NZVC. Confirm `MOVE.L reg→An` (dst id ≥ 8) writes
  An full-32 with no `isMovea` (cf. the RTS/RTR ibranch A7 writeback).

- [ ] **Step 4: Confirm predecode + the 3-µop stash carry EXG.**
  `PredecodeWord.scala` `is(8,9,C,D)` arm: the AND-RMW `memDestExt` would mark a reg-direct

## Task 3: Assemble — the 3-µop EXG crack (MOVE regA→T0 ; regB→regA ; T0→regB)

**Files:** `MicroOpAssembler.scala`; NEW `ExgDecodeSpec.scala`.

- [ ] **Step 1: Detect `isExgOp` + compute the two reg ids.**
  In `MicroOpAssembler.assemble`, near the other opword matches (`isRtrOp` etc.), add:
  ```scala
  val isExgDD = (op(15 downto 12) === B"4'hC") && op(8) && (op(7 downto 3) === B"5'b01000") // EXG Dx,Dy
  val isExgAA = (op(15 downto 12) === B"4'hC") && op(8) && (op(7 downto 3) === B"5'b01001") // EXG Ax,Ay
  val isExgDA = (op(15 downto 12) === B"4'hC") && op(8) && (op(7 downto 3) === B"5'b10001") // EXG Dx,Ay
  val isExgOp = isExgDD || isExgAA || isExgDA
  // reg ids: bits-11:9 reg (regA) + bits-2:0 reg (regB). Data id = field; Addr id = 8+field.
  val exgRx = op(11 downto 9).asUInt
  val exgRy = op(2 downto 0).asUInt
  val exgRegA = Mux(isExgAA, (U(8,5 bits) + exgRx).resized, exgRx.resize(5))           // Dx,Dy/Dx,Ay -> D ; Ax,Ay -> A
  val exgRegB = Mux(isExgAA || isExgDA, (U(8,5 bits) + exgRy).resized, exgRy.resize(5)) // Ay (AA/DA) -> A ; Dy (DD) -> D
  ```
  (regA: data for Dx,Dy & Dx,Ay, address for Ax,Ay. regB: data for Dx,Dy, address for Ax,Ay
  & Dx,Ay.)

- [ ] **Step 2: Build the 3 MOVE µops via `mkUop`.**
  ```scala
  // T0 := regA ; regA := regB ; regB := T0  (full-32 register swap, NO flags)
  val exgU0 = mkUop(srcBReg = exgRegA, srcBValid = True, dstReg = U(T0,5 bits), dstValid = True, first = True)
  val exgU1 = mkUop(srcBReg = exgRegB, srcBValid = True, dstReg = exgRegA,      dstValid = True, first = False)
  val exgU2 = mkUop(srcBReg = U(T0,5 bits), srcBValid = True, dstReg = exgRegB, dstValid = True, first = False)
  ```
  `mkUop` defaults: `op=MOVE`, `cluster=INT`, `size=LONG`, `memOp=NONE`, `writesNzvc=False`,
  `writesX=False`, `isMovea=False`, `useImm=False` — exactly EXG's needs. (Confirm `mkUop`'s
  srcA stays unused; full-32 MOVE.L needs no merge source.)

- [ ] **Step 3: Exclude EXG from `bad` + add the selection arm.**
  Add `!isExgOp` to the `bad` exclusion conjunction (mirror `!isRtrOp`):
  ```scala
  val bad = !isRteOp && … && !isRtsBad && !isRtrBad && !isExgOp && … && (…)
  ```
  Add the EXG arm to the `out.uops`/`out.count` selection chain (place alongside `isRtrOp`,
  BEFORE the line-C ALU fall-through `crackRmw`/`otherwise`):
  ```scala
  } elsewhen(isExgOp) {
    out.count   := 3
    out.uops(0) := exgU0
    out.uops(1) := exgU1
    out.uops(2) := exgU2
  } …
  ```
  Verify EXG does NOT also hit `crackRmw`/`crackLoad`/`crackStore` (EXG's EA is reg-direct →
  `srcIsMem` False → those cracks don't fire; the `isExgOp` arm short-circuits the chain).

- [ ] **Step 4: Write `ExgDecodeSpec`.**
  NEW `src/test/scala/m68k040/decode/ExgDecodeSpec.scala` (mirror `Line5DecodeSpec` — a small
  DUT exposing `MicroOpAssembler.assemble(pkt)`, but expose `.count` + `.uops(0..2)`). For
  each opword assert `count==3`, the 3 µops are `MOVE`, `size==LONG`, `!writesNzvc`,
  `!writesX`, `firstOfInstr = {True,False,False}`, and the srcB/dst reg ids:
  - **`EXG D1,D2` = `0xC342`** (`1100 001 1 01000 010`): regA=D1(=1), regB=D2(=2).
    µ0 srcB=1→dst=T0(16); µ1 srcB=2→dst=1; µ2 srcB=16→dst=2.
  - **`EXG A1,A2` = `0xC34A`** (`1100 001 1 01001 010`): regA=A1(=9), regB=A2(=10).
    µ0 srcB=9→T0; µ1 srcB=10→9; µ2 srcB=16→10.
  - **`EXG D1,A2` = `0xC38A`** (`1100 001 1 10001 010`): regA=D1(=1), regB=A2(=10).
    µ0 srcB=1→T0; µ1 srcB=10→1; µ2 srcB=16→10. (opmode `10001` = EXG Dx,Ay: regA=data
    `op(11:9)`, regB=address `8+op(2:0)`. opmode(8:6)=6.)
  - **`EXG D3,D3` (same reg)** `1100 011 1 01000 011` = `0xC743`: regA=regB=3.
    µ0 srcB=3→T0; µ1 srcB=3→3; µ2 srcB=16→3.
  - **Regression:** an AND-to-Dn (e.g. `AND.B D0,<ea>`/`AND <ea>,D0`) opword still decodes
    `DecOp.AND` (NOT EXG, `count` per AND); and an AND-RMW-to-memory opword unchanged.

  > **Reg-id arithmetic is load-bearing** — compute each opword's exact 16-bit value in the
  > test from the bit fields (`1100 | xxx | 1 | ooooo | yyy`) rather than trusting the hex
  > above; the spec's mapping (D = field, A = 8+field) is the contract.

  Run: `~/sbt/bin/sbt 'testOnly m68k040.decode.ExgDecodeSpec'` — expected PASS.

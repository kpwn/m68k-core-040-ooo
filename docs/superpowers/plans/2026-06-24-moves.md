# MOVES Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Implement MOVES `.B/.W/.L` (68010+ privileged move to/from alternate address space) + real SFC/DFC registers, byte-identical vs Musashi.

**Architecture:** MOVES is a flat memory access (Musashi ignores the FC — `(void)fc`), so it trace-matches a normal MOVE + the An side effect + register state + privilege trap. Cracked through the microcode-v2 engine (~2 µops), reusing the CAS auto-inc/dec EA machinery. SFC/DFC become real 3-bit SystemState regs (also fixes a latent MOVEC RAZ-WI divergence).

**Tech Stack:** SpinalHDL 1.14.1 / Scala 2.13 / Verilator / Vivado 2025.2 (xcku5p-ffvb676-2-e). sbt `~/sbt/bin/sbt`. Oracle = Musashi.

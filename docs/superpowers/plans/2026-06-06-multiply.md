# Multiply (MULU/MULS full 040) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans. Checkbox steps, TDD. Final gate = HONEST **POST-ROUTE** synth (`impl_FullCore.tcl`) — NOT OOC-synth (it's ~15-25 MHz optimistic). Must not regress master's ~243 post-route baseline.

**Goal:** MULU/MULS .W (16×16→32), .L32 (32×32→32 + overflow V), .L64 (32×32→64 Dh:Dl) on the CPLX cluster, reusing the divider's EU + DIVREM 2nd-dest crack. Lock-stepped vs Musashi.

**Architecture:** A DSP48-inferred multiply (registered `a*b` → hard blocks) in the CPLX EU (DivEu's home). 2 source operands only (no 3rd-source `psrcC` — so it avoids the divider's post-route-limiting cone). The 64-bit Dh:Dl result cracks like DIV 64÷32: a MUL µop writes Dl + a MULHI crack writes Dh from the latched high-product. No trap.

**Tech Stack:** SpinalHDL / sbt `~/sbt/bin/sbt` / Verilator / Vivado. Reference: `execute/{DivEuPlugin,DivCore,DivUnit}.scala` (the CPLX EU + the 64-bit crack/wakeup template), `decode/{OperationDecoder,MicroOpAssembler}.scala` (line C opmode 3/7 already flagged isMulDiv→illegal; the DIV.L crack as the .L template), `execute/iq/IssueQueuePlugin.scala` (CPLX port), `rename/RenamedUop.scala`, `rob/RobPlugin.scala`, `lockstep/ExecuteLockStepSpec.scala`, `oracle/Musashi.scala`.

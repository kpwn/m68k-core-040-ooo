# Extended add/subtract (ADDX/SUBX, REGISTER form) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the register form of **ADDX Dy,Dx** (`Dx := Dx + Dy + X`, line D) and
**SUBX Dy,Dx** (`Dx := Dx - Dy - X`, line 9), `.B/.W/.L`. Flags NZVCX with the 68k
**clear-only Z** (`Z := Z_old && result==0`, exactly like the already-implemented NEGX),
size-merged `.B/.W` writeback (preserve Dx's upper bits).

**Architecture:** New `DecOp.ADDX` / `DecOp.SUBX` (next to `NEGX`). Decode by carving the
**Dn-direct EA-mode (bits 5:3 == 000)** slot out of the line-9/D **RMW opmode** space
(bit8=1) — that slot is not a valid ADD/SUB encoding, it IS ADDX/SUBX. The operands fall
out of the existing shapes: srcA = `dnField` (Dx, bits 11:9), srcB = `easrc` (the EA field
`000yyy` → `EaDecoder` DATAREG Dy, bits 2:0), dst = Dx — a single ALU µop, no crack. The
ALU EU runs the existing one-adder ADD/SUB datapath with **X folded into the carry-in**
(ADDX `cin:=X`, SUBX `cin:=!X`, the NEGX borrow form) and the **NEGX clear-only-Z** reused.
Fast path, latency-1.

**Tech Stack:** SpinalHDL 1.14.1 / Scala 2.13 / sbt at `~/sbt/bin/sbt` (NOT on PATH) /
Verilator / Vivado 2025.2 (`xcku5p-ffvb676-2-e`, OOC 4 ns). Lock-step vs
`m68k040.oracle.Musashi`.

**Working dir:** isolated git worktree on `feat/addx-subx` off current `master`
(`c898892`). Run `sbt`/`vivado` from the worktree root.

**Discipline (HARD):** `sbt` not on PATH → `~/sbt/bin/sbt`. NEVER run Verilator+Vivado
concurrently. NEVER the whole `ExecuteLockStepSpec` (OOMs) — `-z` subsets, each its OWN
`JAVA_OPTS=-Xmx10g timeout 1000 ~/sbt/bin/sbt …` JVM (never batch fastTest+lockstep+IPC).
Before vivado: `pgrep -af vivado`, spare any `030`. **The gate is ≥200 MHz now** (relaxed;
the 250 push is deferred — [[synth-gate-every-slice]]).

**Templates to mirror (read these first):** **NEGX** — its `DecOp` element + the decode in
`OperationDecoder.scala` line-4 unary block (`is(0x0)` of `o4`: `op:=NEGX`,
`readsX/readsNzvc/writesX/writesNzvc`), the X carry-in (`cmd.xIn`, `cin := !cmd.xIn`) in
`AluDatapath.scala`, and the **clear-only Z** (`negxZ = rsp.nzvc(2) && s1Nzvc(2)`;
`aluNzvc = Mux(isNegx, negxNzvc, rsp.nzvc)`) in `AluEuPlugin.scala`. The line-8/9/C/D

- [ ] **Step 1: Add `DecOp.ADDX` + `DecOp.SUBX`**

comment:
```scala
//   ADDX : Dx := Dx + Dy + X (NZVCX; reads X + old Z; Z CLEAR-ONLY, like NEGX).
//   SUBX : Dx := Dx - Dy - X (NZVCX; reads X + old Z; Z CLEAR-ONLY, like NEGX).
```
No new `DecodedUop`/`OpSpec` field — X-in (`readsX`/`cmd.xIn`) and old-Z (`readsNzvc`)

- [ ] **Step 2: Carve ADDX/SUBX out of the line-9/D RMW slot**

In `OperationDecoder.scala`, in the `is(0x8, 0x9, 0xB, 0xC, 0xD)` block, add the detector
near the other `is*` predicates (`isEor`, `isDivuW`, …):
```scala
        val eaMode     = opword(5 downto 3)
        // ADDX/SUBX register form: line D/9, RMW opmode (bit8=1, ss in .B/.W/.L), EA mode
        // 000 = Dn-direct. That slot is NOT a valid ADD/SUB encoding (a Dn-direct RMW dst
        // is illegal), so it IS ADDX (line D) / SUBX (line 9): Dx := Dx +/- Dy +/- X.
        val isAddxSubx = isRmw && (line === 0x9 || line === 0xD) && (eaMode === U"000")
```
Add it as the **first** arm of the `when/elsewhen` chain (before `isDivuW || isDivsW`,
`isMuluW/isMulsW`, `isEor`, the `isRmw` mem path) so it wins the mode-000 slot:
```scala
        when(isAddxSubx) {
          o.illegal := False
          o.op   := Mux(line === 0xD, DecOp.ADDX, DecOp.SUBX)
          o.srcA := dnField      // Dx (bits 11:9), the dst operand `a` (read + written)
          o.srcB := easrc        // EA 000yyy -> EaDecoder DATAREG Dy = source `b`
          o.dst  := dnField; o.dstWrites := True
          when(opmode === 4) { o.size := Size.BYTE }
            .elsewhen(opmode === 5) { o.size := Size.WORD }
            .otherwise { o.size := Size.LONG }
          o.writesNzvc := True; o.writesX := True   // NZVC + X (X = carry/borrow out)
          o.readsX     := True                      // X carry/borrow IN (like NEGX)
          o.readsNzvc  := True                      // old Z for the clear-only-Z merge
        } .elsewhen(isDivuW || isDivsW) {
          … (existing arms unchanged) …
```
Confirm `isAddxSubx` excludes the existing arms: the memory-form ADDX/SUBX (bit3=1 →
`eaMode = 001`) and every legitimate ADD/SUB-to-memory RMW (`eaMode ≠ 000`) keep
`isAddxSubx=false` and stay on the existing `isRmw` path; ADD/SUB `<ea>,Dn` (bit8=0,
`!isRmw`) and ADDA/SUBA (opmode 3/7) are unaffected.

- [ ] **Step 3: Write `AddxSubxDecodeSpec`**

NEW `src/test/scala/m68k040/decode/AddxSubxDecodeSpec.scala` (mirror `Line4DecodeSpec`/

- `ADDX D2,D3` .L = `0xD782` (`1101 011 1 10 000 010`): op=ADDX, size=LONG, srcA→D3 (Dx),

- `SUBX D0,D1` .B = `0x9300` (`1001 001 1 00 000 000`): op=SUBX, size=BYTE, srcA→D1,

- `ADDX D5,D5` .W = `0xDB45` (`1101 101 1 01 000 101`): srcA→D5, srcB→D5 (Dx==Dy).
- **Negative guards:** `ADD.L D2,D3` = `0xD682` (bit8=0) → op=ADD, NOT ADDX; `ADDA.L
  A2,A3` (opmode 7) → op=ADD/ADDA (NOT ADDX); `ADDX -(A2),-(A3)` = `0xD78A` (bit3=1, EA
  mode 001) → illegal/deferred (NOT ADDX, NOT a stray ADD writing a reg).

## Task 2: Execute — X carry-in + clear-only-Z in the ALU EU

**Files:** `AluDatapath.scala`, `AluEuPlugin.scala`.

- [ ] **Step 1: Fold X into the adder carry-in (ADDX/SUBX) in `AluDatapath`**

In `AluDatapath.scala`, extend the arithmetic predicates and the `aEff/bEff/cin`/flag
selects (the operands are the ordinary two-operand shape `a=src1=Dx`, `b=src2=Dy` — only
NEG/NEGX force `aEff=0`):
```scala
    val isAddx  = cmd.op === DecOp.ADDX
    val isSubx  = cmd.op === DecOp.SUBX
    val isArith = cmd.op === DecOp.ADD || isSub || isNeg || isNegx || isAddx || isSubx
    val aEff = Mux(isNeg || isNegx, U(0, 32 bits), a)                 // ADDX/SUBX use a
    val bEff = Mux(isNeg || isNegx, ~a, Mux(isSub || isSubx, ~b, b))  // SUBX subtracts (~b)
    val cin  = Mux(isNegx || isSubx, !cmd.xIn,                        // SUBX borrow = !X
                 Mux(isSub || isNeg, True,                            // SUB/NEG = 1
                   Mux(isAddx, cmd.xIn, False)))                      // ADDX carry = X; ADD = 0
```
Then include SUBX in the **borrow** flavour of the C/X select and leave ADDX on the
**carry** flavour:
```scala
    val cFlag = Mux(isArith, Mux(isSub || isNeg || isNegx || isSubx, ~cout, cout), False)
```
`vFlag := Mux(isArith, vArith, False)` already covers ADDX/SUBX (added to `isArith`); the
result mux `default -> sum32` and `xOut := cFlag` already cover them. The `piece(w)` N/Z/V
use `aEff/bEff/cin`, so they compute the correct size-bounded N, raw Z, signed V for both.

- [ ] **Step 2: Generalize the clear-only-Z to NEGX/ADDX/SUBX in `AluEuPlugin`**

In `AluEuPlugin.scala`, replace the NEGX-only Z-clear with the extended family:
```scala
    val isExtended = (u1.op === DecOp.NEGX) || (u1.op === DecOp.ADDX) || (u1.op === DecOp.SUBX)
    val extZ       = rsp.nzvc(2) && s1Nzvc(2)                 // raw Z AND old Z (clear-only)
    val extNzvc    = rsp.nzvc(3) ## extZ ## rsp.nzvc(1 downto 0)
    val aluNzvc    = Mux(isExtended, extNzvc, rsp.nzvc)
```
(`s1Nzvc(2)` is the old Z; valid because these µops set `readsNzvc`. N/V/C and X are the
datapath's. The size-merge of the int writeback is unchanged — the merge source is
`s1Src1 = srcA = Dx`, so `.B/.W` preserve Dx's upper bits.) ADDX/SUBX are NOT `isSlow`
(only SHIFT is) → they stay latency-1.

## Task 3: Lock-step matrix + test-fast + synth gate

**Files:** `ExecuteLockStepSpec.scala` (add tests); run-only for the gates.

- [ ] **Step 1: Add the ADDX/SUBX lock-step matrix**

In `ExecuteLockStepSpec.scala` (mirror the NEGX / ADD lock-step tests — assemble a short
program, run DUT vs Musashi, compare regs + CCR), add tests covering:
- **{ADDX,SUBX} × {.B,.W,.L} × {X=0, X=1}.** Seed X with a prior op (e.g. an `addq`/`move
  to %ccr` that yields a known carry/X) and Dx/Dy with `move.l #…`. Assert result, **X =
  carry/borrow out**, N (MSB at size), V (overflow), C.
- **Multi-precision chain:** two back-to-back ADDX limbs forming a 64-bit add (low limb
  sets X, high limb consumes it); the SUBX twin. Use a low-limb value that overflows (X=1
  into the high limb) AND one that does not (X=0).
- **Clear-only Z:** set Z=0 (prior non-zero result), then an ADDX/SUBX with result==0 →
  assert **Z stays 0**. Mirror: Z=1 preceding + zero result → Z stays 1; non-zero result →
  Z clears to 0.
- **Overflow/borrow edges:** `.B 0x7F + 1` (V=1,N=1), `.B` SUBX borrow at `0x80`, `.L
  0x7FFFFFFF + 0 + X(=1)` (V from the X increment), `.W 0x8000` boundary.
- **Upper-byte preservation:** seed Dx upper half non-zero, do a `.B`/`.W` ADDX/SUBX,
  assert the upper bits survive.
Use the reg-seed pattern (`move.l #X,%d0 ; … ; addx.l %d1,%d0`) the other lock-step tests
use.

# Bit Operations (BTST/BSET/BCLR/BCHG) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement BTST/BSET/BCLR/BCHG (static + dynamic forms, Dn-dest + memory-dest): test bit *n* → Z = complement of that bit, and (all but BTST) set/clear/toggle it.

**Architecture:** New `DecOp.BITOP` + a 2-bit `bitOp` sub-kind (mirroring `DecOp.SHIFT`/`shiftOp`). Decode in `OperationDecoder` line-0 (dynamic `bit8=1` / static opmode-4); the assembler resolves the EA → register form (one BITOP µop, size LONG, bit mod 32) or memory form (BYTE, bit mod 8: BTST load-only, BSET/BCLR/BCHG via the existing mem-RMW crack). The ALU EU runs the bit-op datapath with a **Z-only** flag write.

**Tech Stack:** SpinalHDL 1.14.1 / Scala 2.13 / sbt at `~/sbt/bin/sbt` (NOT on PATH) / Verilator / Vivado 2025.2 (`xcku5p-ffvb676-2-e`, OOC 4 ns). Lock-step vs `m68k040.oracle.Musashi`.

**Working dir:** isolated git worktree on `feat/bit-ops` off current `master` (`c898892`). Run `sbt`/`vivado` from the worktree root.

**Discipline (HARD):** `sbt` not on PATH → `~/sbt/bin/sbt`. NEVER run Verilator+Vivado concurrently. NEVER the whole `ExecuteLockStepSpec` (OOMs) — `-z` subsets, each its OWN `JAVA_OPTS=-Xmx10g timeout 1000 ~/sbt/bin/sbt …` JVM (never batch fastTest+lockstep+IPC). **Templates to mirror (read these first):** `DecOp.SHIFT`+`shiftOp` (op-with-subkind field) in `DecodedUop.scala`; the line-0 immediate decode in `OperationDecoder.scala:34-58` (the `is(0x0)` block) and how `OpSpec` names operands (`easrc`/`dnField`/`immext`); the mem-RMW crack in `MicroOpAssembler.scala` (line-0/line-4 to memory: load→op→store, BTST-style load-only for TST-mem); the ALU EU op-mux + the partial-flag handling (NEGX Z, ANDI-to-CCR flag-RMW) in `AluDatapath.scala`/`AluEuPlugin.scala`.

## Task 1: DecOp.BITOP + bitOp field + line-0 decode + decode spec

**Files:** `DecodedUop.scala`, `OperationDecoder.scala`, NEW `BitOpDecodeSpec.scala`.

- [ ] **Step 1: Add `DecOp.BITOP` + the `bitOp` field**

In `DecodedUop.scala`, add `BITOP` to the `DecOp` enum (next to `SHIFT`). Add the µop field
(near `shiftOp`):
```scala
  // Bit op (BTST/BCHG/BCLR/BSET): tt = 00 BTST, 01 BCHG, 10 BCLR, 11 BSET. Bit number is
  // the immediate (static form, useImm) or srcB=Dn (dynamic). Dest width: LONG (Dn, bit
  // mod 32) or BYTE (memory, bit mod 8) — set by the assembler from the EA. Default 0.
  val bitOp = Bits(2 bits)
```
Drive a default `bitOp := 0` wherever the assembler/decoder zero-inits a fresh uop/OpSpec.

- [ ] **Step 2: Add `bitOp` to `OpSpec` + decode the line-0 bit-ops**

In `OperationDecoder.scala`, add `val bitOp = Bits(2 bits)` to `OpSpec` (default 0). In the
`is(0x0)` block, alongside the existing `isImm` immediates, add bit-op detection. `mode =
opword(5 downto 3)`, `tt = opword(7 downto 6)`:
```scala
        // Bit ops: dynamic 0000 rrr 1 tt mmmrrr (bit8=1, NOT mode 001=MOVEP); static
        // 0000 1000 tt mmmrrr (bits 11:8 == 1000). tt: 00 BTST,01 BCHG,10 BCLR,11 BSET.
        val mode    = opword(5 downto 3)
        val tt      = opword(7 downto 6)
        val isDynBit = opword(8) && (mode =/= U"001")                 // exclude MOVEP
        val isStatBit= opword(11 downto 8) === B"1000"                // opmode 4, bit8=0
        when(isDynBit || isStatBit) {
          o.illegal := False
          o.op    := DecOp.BITOP
          o.bitOp := tt
          o.srcA  := easrc                       // the destination operand (tested + written)
          o.srcB  := Mux(isDynBit, dnField, immext)  // bit number: Dn (dyn) or ext word (stat)
          o.dst   := easrc
          o.dstWrites := (tt =/= U"00")          // BTST writes nothing
          o.writesNzvc := True                   // Z computed; assembler/EU preserve N/V/C
          // size is dest-dependent (Dn=LONG, mem=BYTE) -> resolved in the assembler.
        }
```
Ensure this does NOT also match the existing immediates (it won't: `isImm` requires
`!bit8` and opmode ∈ {0,1,2,3,5,6}; static bit-op is opmode 4, dynamic is bit8=1). MOVES
(opmode 7, bit8=0) stays illegal.

- [ ] **Step 3: Write `BitOpDecodeSpec`**

**Files:** `MicroOpAssembler.scala`; extend `BitOpDecodeSpec` for the assembler view.

- [ ] **Step 1: Assemble the BITOP µop with dest-resolved size**

In `MicroOpAssembler.scala`, where the EA is resolved to a register vs memory form (mirror
how line-0 immediates / line-4 unary resolve `easrc`), special-case `op === DecOp.BITOP`:
- **EA = Dn (data reg direct):** one BITOP µop. `size := LONG`; srcA = Dn (the tested data),
  bitNumber = imm (static) or srcB=Dn (dynamic); dst = Dn with `dstWrites = bitOp != BTST`;
  `writesNzvc := True`, `writesX := False`. (Z-only is enforced in the EU; the µop writes
  NZVC but the EU preserves N/V/C — see Task 3.) `readsNzvc := True` (the EU needs old N/V/C
  to preserve them).
- **EA = memory:** `size := BYTE`. **BTST** → a LOAD µop that computes flags from the loaded
  byte with NO store (mirror TST-to-memory load-only: load byte → BITOP flags → no store
  µop). **BSET/BCLR/BCHG** → the mem-RMW crack (load byte → BITOP µop on the byte → store
  byte), exactly like the line-0/line-4 mem-RMW path. The bit number (imm/Dn) feeds the
  BITOP µop; bit mod 8 is applied in the EU from `size==BYTE`.

Keep memory EA support to the modes the current mem-RMW already handles (`(An)`,`(d16,An)`,
`(xxx).W/.L`); a not-yet-supported EA mode routes to the existing illegal/deferred path.

## Task 3: Execute — bit-op datapath + Z-only flag in the ALU EU

**Files:** `AluDatapath.scala` and/or `AluEuPlugin.scala`.

- [ ] **Step 1: Add the bit-op datapath**

Where the ALU EU muxes by `DecOp` (mirror how `SHIFT` is muxed / line-4 unary ops compute),
add the BITOP case on the fast path:
```scala
    // Bit op: bn = bitNumber mod (LONG?32:8); mask = 1<<bn; Z = (data & mask)==0;
    // result = BTST:data / BCHG:^ / BCLR:&~ / BSET:|. data = srcA (Dn long, or the loaded
    // byte for a mem RMW; size selects the modulo + the operate width).
    val bnRaw = Mux(u.useImm, u.imm.asUInt, srcB.asUInt)         // bit number source
    val bn    = Mux(u.size === Size.LONG, bnRaw(4 downto 0), bnRaw(2 downto 0).resize(5))
    val bmask = (U(1, 32 bits) << bn).asBits
    val bdata = srcA                                              // tested data (Dn or byte)
    val bTestZ= (bdata & bmask) === 0
    val bRes  = u.bitOp.mux(
      B"00" -> bdata,                 // BTST: no change
      B"01" -> (bdata ^ bmask),       // BCHG
      B"10" -> (bdata & ~bmask),      // BCLR
      B"11" -> (bdata | bmask))       // BSET
```
Route `bRes` into the int writeback mux for `op===BITOP` (gated by `dstWrites`), and `bn`'s
modulo by size. For the BYTE (memory) form the operate/merge is on the low byte (the loaded
byte is in srcA's low 8 bits; the store µop writes the byte back) — follow the existing
byte-size writeback/merge used by line-4 mem-RMW.

- [ ] **Step 2: Z-only flag write (preserve N/V/C, X)**

Bit-ops set **only Z**. Reuse the EU's partial-flag mechanism (the same path that does
ANDI-to-CCR / NEGX's partial Z — it reads the old NZVC). For `op===BITOP`, the NZVC written
is `{N_old, bTestZ, V_old, C_old}` (old N/V/C from the read NZVC, Z = `bTestZ`), and X is
NOT written (`writesX=False`). Implement as: when `op===BITOP`, `finalNzvc := oldN ##
bTestZ ## oldV ## oldC` (oldN/oldV/oldC from the EU's NZVC read, mirroring the NEGX/toCcr
merge), instead of the datapath's raw nzvc.

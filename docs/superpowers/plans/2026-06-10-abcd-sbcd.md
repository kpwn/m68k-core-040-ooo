# Packed-BCD add/subtract (ABCD/SBCD, register form) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement ABCD (`Dx := BCD(Dx + Dy + X)`, line C) and SBCD (`Dx := BCD(Dx - Dy - X)`, line 8) in their **register (data-reg → data-reg) BYTE form**: a binary add/sub of the low bytes plus the 68k decimal-adjust correction, writing the corrected BCD byte into `Dx[7:0]` (preserving `Dx[31:8]`).

**Architecture:** New `DecOp.BCD` + a 1-bit `bcdSub` sub-kind (0=ABCD add, 1=SBCD subtract), mirroring `DecOp.SHIFT`/`shiftDir`. Decode in the line-8/C block of `OperationDecoder` (carve `1xx0 xxx 1 0000 0 yyy` off the AND/OR-RMW path, which currently makes that pattern illegal). The assembler emits one register-direct ALU µop (srcA=Dx, srcB=Dy, dst=Dx, BYTE). The ALU EU runs the **BCD decimal-adjust datapath tuned to bit-match Musashi** — including Musashi's specific N/V (officially "undefined", but the lock-step compares the **full CCR byte** with no masking, so N/V are COMPARED), C/X = decimal carry/borrow, and a clear-only Z (NEGX mechanism).

**Tech Stack:** SpinalHDL 1.14.1 / Scala 2.13 / sbt at `~/sbt/bin/sbt` (NOT on PATH) / Verilator / Vivado 2025.2 (`xcku5p-ffvb676-2-e`, OOC 4 ns). Lock-step vs `m68k040.oracle.Musashi`. Golden BCD reference: `tools/musashi/musashi/m68k_in.c` (`m68k_op_abcd_8_rr` ~L941, `m68k_op_sbcd_8_rr` ~L9361).

**Working dir:** isolated git worktree on `feat/abcd-sbcd` off current `master` (`c898892`). Run `sbt`/`vivado` from the worktree root.

**Discipline (HARD):** `sbt` not on PATH → `~/sbt/bin/sbt`. NEVER run Verilator+Vivado concurrently. NEVER the whole `ExecuteLockStepSpec` (OOMs) — `-z` subsets, each its OWN `JAVA_OPTS=-Xmx10g timeout 1000 ~/sbt/bin/sbt …` JVM (never batch fastTest+lockstep+IPC). Before vivado: `pgrep -af vivado`, spare any `030`. **The gate is ≥200 MHz now** (relaxed; the 250 push is deferred — [[synth-gate-every-slice]]).

## Task 3: Execute — BCD decimal-adjust datapath + flags (Musashi-matched)

**Files:** `AluEuPlugin.scala` (preferred — EU-side block, reuses `s1X`/`s1Nzvc`), optionally `AluDatapath.scala`.

- [ ] **Step 1: Add the BCD decimal-adjust datapath**

**Read `m68k_op_abcd_8_rr` and `m68k_op_sbcd_8_rr` verbatim first** (`tools/musashi/musashi/
m68k_in.c`). In `AluEuPlugin.scala`'s S1 (alongside the NEGX/toCcr merges), compute the BCD
result + flags from `dx = s1Src1(7 downto 0)`, `dy = s1Src2(7 downto 0)`, `xin = s1X`,
`zOld = s1Nzvc(2)`. Work in a **wide unsigned lane** (use `UInt(10 bits)` or wider so the
`>0x99` test and SBCD's borrow wrap behave like Musashi's `uint`):

```scala
    val isBcd  = u1.op === DecOp.BCD
    val dx     = s1Src1(7 downto 0).asUInt
    val dy     = s1Src2(7 downto 0).asUInt
    val xin    = s1X.asUInt                      // 0/1
    // ── ABCD (add) ──
    val aLoSum = (dx(3 downto 0) +^ dy(3 downto 0) +^ xin)        // 0..0x13, wide
    val aVraw  = ~aLoSum                                          // V part I (full width)
    val aLoAdj = Mux(aLoSum > 9, aLoSum + 6, aLoSum)
    val aFull  = aLoAdj + (dx(7 downto 4) ## U"0000").asUInt + (dy(7 downto 4) ## U"0000").asUInt
    val aCarry = aFull > 0x99
    val aRes   = Mux(aCarry, aFull - 0xA0, aFull)                // pre-mask res
    val aV     = (aVraw & aRes)(7)                                // V part II (ABCD: pre-mask res)
    val aN     = aRes(7)
    val aRes8  = aRes(7 downto 0)
    // ── SBCD (subtract) ── (unsigned wrap is intentional)
    val sLoSub = (dx(3 downto 0).resize(?) - dy(3 downto 0) - xin)  // allow wrap; wide signed/unsigned per C
    val sVraw  = ~sLoSub
    val sLoAdj = Mux(sLoSub > 9, sLoSub - 6, sLoSub)
    val sFull  = sLoAdj + (dx(7 downto 4) ## U"0000").asUInt - (dy(7 downto 4) ## U"0000").asUInt
    val sBorrow= sFull > 0x99
    val sRes   = Mux(sBorrow, sFull + 0xA0, sFull)
    val sRes8  = sRes(7 downto 0)
    val sV     = (sVraw & sRes8.resize(sVraw))(7)                 // V part II (SBCD: masked res)
    val sN     = sRes8(7)
    // select by bcdSub
    val bcdRes8  = Mux(u1.bcdSub, sRes8, aRes8)
    val bcdCarry = Mux(u1.bcdSub, sBorrow, aCarry)               // C = X = decimal carry/borrow
    val bcdN     = Mux(u1.bcdSub, sN, aN)
    val bcdV     = Mux(u1.bcdSub, sV, aV)
    val bcdZ     = zOld && (bcdRes8 === 0)                        // CLEAR-ONLY
```
**The `?`/`resize(...)` widths above are placeholders — match Musashi's `uint` (32-bit
unsigned) semantics exactly. The lock-step is the arbiter; do NOT hand-optimize the widths
until lock-step is green.** In particular replicate SBCD's unsigned wrap: in C `res` is a
`uint`, so `LOW_NIBBLE(dst) - LOW_NIBBLE(src) - X` underflows to a huge value when negative,
which makes `res > 9` true → `-6`. Use a wide unsigned and let it wrap, comparing `> 9` /
`> 0x99` unsigned, just like the C.

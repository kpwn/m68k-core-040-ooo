# LS Cluster Slice 1 — Load/Store Path + VIPT L1D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. This is a multi-component subsystem — each task produces an independently-testable unit; the synth gate is the final task and is mandatory.

**Goal:** A correct (not-yet-fast) memory path — AGU + VIPT write-through L1D + store queue with store→load forwarding + commit-time drain, identity translation, aligned-only — driven by load/store µops injected on a new IQ LS port, with variant-(A) dynamic-completion load wakeup, holding the full-core synth ≥250 MHz.

**Architecture:** A new `LsEuPlugin` (shaped like `AluEuPlugin`) runs AGU → translate (parallel) → L1D/SQ → writeback. The L1D (`DcachePlugin`) is modeled on the proven `IcachePlugin` (BRAM data, 2-cycle read, `TranslationService`) but VIPT + write-through/no-allocate/never-dirty with a 128-bit line = one AXI beat. A `StoreQueue` holds speculative stores, forwards to younger loads, and drains in commit order on ROB retire. The IQ gains a 4th issue port (LS class = `cluster===LS`) and one dynamic-completion wakeup source.

**Tech Stack:** SpinalHDL 1.14.1 / Scala 2.13 / sbt at `~/sbt/bin/sbt` (NOT on PATH) / Verilator / Vivado (xcku5p-ffvb676-2). Reference files to read and mirror: `cache/IcachePlugin.scala` (BRAM cache + AXI + `TranslationService` + `CacheGeometry`), `execute/AluEuPlugin.scala` (EU pipeline shape, PRF read/write, completion, `wbObs`), `execute/iq/IssueQueuePlugin.scala` (issue ports + class select + wakeup), `rob/RobPlugin.scala` (commit ports, `doFlush`), the I-cache sim harness for the behavioral AXI memory. Spec: `docs/superpowers/specs/2026-06-03-ls-cluster-1-design.md`.

**Branch:** create `feat/ls-cluster-1` off `master` before Task 1.

**Conventions (verified):** µop bundles are `DecodedUop` (decode→rename) / `RenamedUop` (rename→backend) / `IqContext{uop, robId}`. Both uop bundles already carry `cluster:Cluster{INT,EA,LS,CPLX}` and `size:Size`. `MemOp{NONE,LOAD,STORE}` exists in `isa/Isa.scala` but is NOT yet on the µop. Reg ids: D0–7=0–7, A0–7=8–15. EU pattern: `during setup` allocates ports (`irf.newRead/newWrite/newBypass`, `Stream(IqContext())`, `Flow(UInt(6 bits))` completion); `logic = during build` runs S0|M2S(`RegNext`)|S1; sim `wbObs` is `simPublic`. IQ `issue:Vec[Stream[IqContext]]` is length 3 (ALU0/ALU1/branch); class select uses `context.uop.isBranch`.

### Task 3: VIPT write-through L1D (`DcachePlugin`)

**Files:**
- Create: `src/main/scala/m68k040/cache/DcachePlugin.scala`, `src/main/scala/m68k040/cache/DcacheTypes.scala`
- Test: `src/test/scala/m68k040/cache/DcacheSpec.scala`

Model structurally on `IcachePlugin` (READ IT FIRST). Differences: `CacheGeometry(cacheBytes=8192, lineBytes=16, ways=4, indexingPolicy=CacheIndexingPolicy.Vipt)`; a **store/write port** (write-through/no-allocate); a 128-bit AXI for refill reads + write-through writes; consumes `TranslationService`.

**Interface (`DcacheTypes.scala`):**
```scala
case class DLoadCmd()  extends Bundle { val vaddr = UInt(32 bits); val size = Size() }
case class DLoadRsp()  extends Bundle { val data = Bits(32 bits); val fault = Bool() } // byte-lane-extracted, size-aware
case class DStoreCmd() extends Bundle { val paddr = UInt(32 bits); val data = Bits(32 bits); val size = Size() } // physical; from SQ drain
trait DcacheService {
  def loadCmd:  Stream[DLoadCmd]   // virtual; cache translates (VIPT) + reads
  def loadRsp:  Flow[DLoadRsp]     // fixed offset for a hit; valid late on a miss-refill
  def loadBusy: Bool               // high while a refill is in flight (back-pressures new loads)
  def store:    Flow[DStoreCmd]    // write-through: update line if hit + write memory
}
```

- [ ] **Step 1: Write the failing test** — a Dut hosting `DcachePlugin` + `IdentityTranslationPlugin` + `BehavioralMem`. Cases (each TWO runs for determinism): (a) preload memory, `loadCmd` a cold addr → miss → refill (one 128-bit beat) → `loadRsp.data` = the size-extracted bytes; (b) re-load same addr → hit (no refill, `loadBusy` stays low); (c) `store` to a hit line → subsequent load sees new data AND `BehavioralMem` was written (write-through); (d) `store` to a missing line → memory written, no line allocated (re-load still misses then refills the new value); (e) byte/word/long size extraction + big-endian byte order.

- [ ] **Step 2: Run — FAIL** (undefined).

- [ ] **Step 3: Implement** `DcachePlugin`:
  - Arrays: `dataMem = Mem(Bits(128 bits), sets*ways)` (BRAM, `readSync` 1-cycle like the I-cache); `tags = Vec.fill(ways)(Mem(Bits(tagBits+1 bits)...))` or `Reg`-array of `{valid, tag}` per (set,way) (small LUTRAM).
  - Load pipe (2-cycle, mirror I-cache S0/S1): S0 — `index = vaddr(offsetHi:..)`, issue `dataMem.readSync(set,way)` for all ways, issue `TranslationService.req(vpn=vaddr(31 downto 12))`; S1 — physical tag = `rsp.ppn ## vaddr(11 downto offsetBits)` high bits, compare to each way's stored tag+valid → `hitOh`; on hit, `OhMux` the way data → byte-lane extract by `size` + offset (big-endian) → `loadRsp`. On miss: assert `loadBusy`, AXI `ar` for the line (len so one 128-bit beat = whole line: `len=0`), on `r` fill `dataMem(set,fillWay)` + tag + valid, then drive `loadRsp` with the extracted bytes; round-robin `fillWay`.
  - Store port (write-through): translate is NOT needed here (the SQ provides a PHYSICAL paddr at drain). Compute set/tag from paddr; if a way hits → write the `size` bytes into that way's line (read-modify-write the 128-bit word with byte enables) ; ALWAYS issue an AXI write (`aw`/`w` with byte strobes for the `size` bytes) to memory (write-through). No allocate on miss.
  - Endianness: byte-lane swap in the extract/format helpers (a shared `object DcacheByteLane`).
  - Use `M68kSpinalConfig` multi-write lowering for any multi-write arrays (the phase already exists).

- [ ] **Step 4: Run — PASS** (all cases, ×2). If `dataMem.readSync` latency shifts a cycle, fix the test's wait to poll `loadRsp.valid` (do not change asserted data).

### Task 4: Store queue (`StoreQueue`) — alloc / forward / commit-drain / squash

**Files:**
- Create: `src/main/scala/m68k040/ls/StoreQueue.scala`
- Test: `src/test/scala/m68k040/ls/StoreQueueSpec.scala`

A small ring (depth 8, parametric). Pure logic component (no AXI; drives the `DcacheService.store` at drain).

**Interface:**
```scala
case class SqAlloc() extends Bundle { val robId=UInt(6 bits); val paddr=UInt(32 bits); val data=Bits(32 bits); val size=Size() }
case class SqFwdQuery() extends Bundle { val robId=UInt(6 bits); val paddr=UInt(32 bits); val size=Size() }
case class SqFwdRsp() extends Bundle { val hit=Bool(); val data=Bits(32 bits); val stall=Bool() } // hit=full-overlap forward; stall=partial/ambiguous overlap with an older store
class StoreQueue(depth:Int=8) extends Component {
  val io = new Bundle {
    val alloc   = slave Flow(SqAlloc())          // store executes -> allocate (speculative)
    val fwd     = new Bundle { val query=in(SqFwdQuery()); val rsp=out(SqFwdRsp()) } // load forward check
    val commit  = slave Flow(UInt(6 bits))       // ROB retired this robId -> mark committed
    val flush   = in Bool()                       // mispredict: squash speculative (younger) entries
    val drain   = master Flow(DStoreCmd())        // oldest committed entry -> L1D write-through
  }
}
```
Behavior: `alloc` pushes at tail (speculative). `commit(robId)` marks the matching entry committed. The oldest entry, once committed, drives `drain` (one/cycle, in order) then pops. `flush` rolls the tail back to the youngest committed entry (pointer reset — same discipline as ROB/freelist; speculative entries never drained → memory untouched). `fwd`: among entries OLDER than `query.robId` (program order via the ring), find address-overlapping; full same-size overlap → `hit + data` (youngest such); partial/ambiguous → `stall`.

- [ ] **Step 1: Write the failing test** — directed (×2): alloc store A; fwd query (younger) same addr → hit+data; commit A → drain emits A; fwd query no-overlap → no hit; alloc B (younger) then flush → B squashed (never drains), A (older, committed) still drains; partial-overlap → stall. Use a `StoreQueue` Dut and poke the ports.

- [ ] **Step 2: Run — FAIL.**
- [ ] **Step 3: Implement** the ring (`Vec(Reg(entry))`, head/tail/committed pointers; **`RegInit` all state, hardware-sum any counts — no `when`-gated Scala-var counters**, per [[spinalhdl-sim-poke-gotchas]]). Overlap compare across `depth` entries (keep depth small for FMax).

### Task 5: AGU + LS EU (`LsEuPlugin`)

**Files:**
- Create: `src/main/scala/m68k040/execute/LsEuPlugin.scala`
- Test: `src/test/scala/m68k040/ls/LsEuSpec.scala`

Shaped like `AluEuPlugin` (READ IT FIRST). Consumes an `issue:Stream[IqContext]`, an int PRF read port (base) + int write port (load dest), the `DcacheService`, a `StoreQueue` instance (or its ports), and `TranslationService`. Drives a `completion:Flow[UInt]` (robId) + sim `wbObs`.

**Pipeline:** S0 — read base reg (`rdBase`), `va = base + disp` (`disp = u.imm.asSInt`, base from `srcA`); request translation (`vpn=va(31:12)`); M2S register. S1 — receive translation `ppn` → `paddr`; for **LOAD**: drive `dcache.loadCmd(va,size)` AND `sq.fwd.query(robId,paddr,size)`; if `fwd.hit` → use forwarded data (skip cache); elif `fwd.stall` → hold (stall issue of this load — see wakeup note); else use `dcache.loadRsp` (wait for `loadRsp.valid` if a refill is in flight, via `dcache.loadBusy`). On data ready → int PRF write + **dynamic completion wakeup** (`completion.valid` + broadcast robId) + `wbObs`. For **STORE**: `sq.alloc(robId, paddr, storeData=srcB, size)`; completion fires when allocated (store "executes" = SQ-allocated; it drains at commit).

**Service:**
```scala
trait LsEuService { def issue: Stream[IqContext]; def completion: Flow[UInt]; def sqCommit: Flow[UInt]; def sqFlush: Bool }
```
(`sqCommit`/`sqFlush` are wired by the integration task from the ROB.)

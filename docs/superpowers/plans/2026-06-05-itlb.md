# ITLB (instruction-side MMU + fetch-fault delivery) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans. Checkbox steps. The synth gate (final task) is MANDATORY, HONEST (mmuEnable shared+live, not const-folded), and must REPORT the LUT/FF delta.

**Goal:** Give the I-fetch path a real 68040 MMU — banked ITLB + separate hardware table-walker behind the I-side `TranslationService`, sharing the one MMU control with the DTLB — and deliver instruction-fetch faults as precise format-$7 exceptions, holding MMU-live synth ≥250 MHz.

**Architecture:** `ItlbPlugin` ≈ `DtlbPlugin` (a `Tlb` + a separate `TableWalker`) replaces `IdentityTranslationPlugin`. A shared `MmuControlService` holds `mmuEnable`/`rootPtr` (one 68040 MMU) read by both TLBs. An I-fetch fault flows through the existing `DecodePacket.fault → DecodedUop.faulted` path → ROB → the merged commit-side exception FSM stacks format-$7 (SSW instruction bit). The MAME-040 oracle is extended to fault on instruction fetch.

**Tech Stack:** SpinalHDL 1.14.1 / sbt `~/sbt/bin/sbt` / Verilator / Vivado. Reference: `mmu/DtlbPlugin.scala` (the template — Tlb+walker behind a translation service, miss-stall, U/M-write queue), `mmu/Tlb.scala`+`mmu/TableWalker.scala` (reusable), `cache/IcachePlugin.scala` (consumes `TranslationService` + already sets `DecodePacket.fault` from `xlate.rsp.fault`; stalls on miss), `frontend/DecodePacket.scala` (`fault` bit), `decode/*` (DecodedUop `faulted`/`faultVector`), `rob/RobPlugin.scala`+`exception/ExceptionUnit.scala` (format-$7 delivery), `tools/musashi/m68k_ref.cpp`+`m68kcpu.h` (the MAME-040 MMU + $7 oracle graft to extend for I-fetch), `lockstep/ExecuteLockStepSpec.scala`. Spec: `docs/superpowers/specs/2026-06-05-itlb-design.md`.

**Branch:** `feat/itlb` (created; spec committed). **MMU-disabled stays pure identity (existing tests unchanged).**

### Task 3: I-fetch fault → format-$7 delivery wiring
**Files:** Modify `decode/*` (`DecodePacket.fault` → `DecodedUop.faulted`, vector 2, faultAddr=PC, SSW instruction bit), `rob/RobPlugin.scala`/`exception/ExceptionUnit.scala` (carry the SSW-instruction bit into the $7 SSW), `execute/...` as needed; Test `src/test/scala/m68k040/decode/FetchFaultSpec.scala`.
When a `DecodePacket` has `fault`, decode emits a `faulted` µop (vector 2 = access fault, `faultAddr` = the instruction PC, SSW instruction bit set). The exception FSM (already stacks $7 for vector 2) sets the SSW **instruction** bit for fetch faults (vs data). The faulting µop's op is don't-care (it only delivers the exception at retire).

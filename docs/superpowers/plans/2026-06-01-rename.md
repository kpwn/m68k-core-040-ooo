**Goal:** Map `DecodedUop` architectural operands → physical registers, 2-wide, for the 16 integer regs and split CCR (NZVC/X), via a dual-RAM RAT + pointer freelist with intra-group hazards, emitting a `RenamedUop` stream — built FPGA-friendly (250 MHz, no high-fanout).

Commit/flush are test-driven ports (no ROB yet).

**Tech Stack:** Scala 2.13.16 / SpinalHDL 1.14.1 / SpinalSim + Verilator / ScalaTest 3.2.19.

**Spec:** `docs/superpowers/specs/2026-06-01-rename-design.md`. **FMax invariant #2:** no high-fanout signals; async LUTRAM RAT reads; flush fans out only to location bits + freelist pointers; pointer-reset freelist (no broadcast clear).

## Task 1: `RatTable` (generic dual-RAM RAT)

**Files:** Create `src/main/scala/m68k040/rename/RatTable.scala`; Test `src/test/scala/m68k040/rename/RatTableSpec.scala`

**Structural spec** — `case class RatTable(physIdWidth: Int, archDepth: Int, writePorts: Int, commitPorts: Int, readPorts: Int) extends Component`, IO `io`:
- `rollback: in Bool`
- `writes: Vec(writePorts, slave Flow(new Bundle{ addr: UInt(log2Up(archDepth)); data: UInt(physIdWidth) }))`
- `commits: Vec(commitPorts, slave Flow(... same ...))`
- `reads: Vec(readPorts, new Bundle{ addr: in UInt(log2Up(archDepth)); data: out UInt(physIdWidth) })`
Internals (adapt NaxRiscv `TranslatorWithRollback`):
- `specRam = Mem(UInt(physIdWidth bits), archDepth)`, `commitRam = Mem(...)`.
- write-bypass for each write port `i`: `hit_i = OR over j>i of (writes(j).valid && writes(j).addr === writes(i).addr)`; `specRam.write(writes(i).addr, writes(i).data, writes(i).valid && !hit_i)`. Same pattern for commits→commitRam.
- `location = Reg(Bits(archDepth bits)) init 0`; for each arch index `a`: `when(any writes(i).valid && writes(i).addr===a){ location(a) := True }`; `when(rollback){ location := 0 }`.
- reads: `io.reads(r).data := location(io.reads(r).addr) ? specRam.readAsync(io.reads(r).addr) | commitRam.readAsync(io.reads(r).addr)`.
- (No init counter in the component — the RenameStage seeds committed identity mappings, OR add an optional init; for the unit test, drive commits explicitly.)

## Task 2: `Freelist` (pointer-based multi-port allocator)

**Files:** Create `src/main/scala/m68k040/rename/Freelist.scala`; Test `src/test/scala/m68k040/rename/FreelistSpec.scala`

**Structural spec** — `case class Freelist(physCount: Int, archCount: Int, popPorts: Int, pushPorts: Int) extends Component`. A circular buffer holding the FREE phys-ids (initially ids `archCount..physCount-1`; ids `0..archCount-1` are the initial committed mapping, not free). IO:
- `pop: Vec(popPorts, new Bundle{ take: in Bool; id: out UInt(idW) })` + `popReady: out Bool` (true when ≥ (count of asserted `take`) free ids available — for simplicity, `popReady := freeCount >= popPorts` and the stage only pops when ready).
- `push: Vec(pushPorts, slave Flow(UInt(idW)))` (return freed ids).
- `flush: in Bool` (reset head/tail/count to the committed state: all `archCount..physCount-1` free again — pointer reset, NOT per-entry clear).
Internals: `ram = Mem(UInt(idW), physCount)`; `head`/`tail` pointers + `count`. Per cycle: pop advances head by (#takes), push advances tail by (#pushes); `count` updates. On `flush`: head/tail/count reset to the init free set (a pointer + count reset — low fanout). Init (post-reset): a small counter writes ids `archCount..physCount-1` into `ram[0..]` and sets count.
(Keep it simple: `popPorts=pushPorts=2`. The exact distinct-id read for 2 pops = `ram.readAsync(head)`, `ram.readAsync(head+1)`.)

package m68k040.rename

import m68k040.VerilatorTest
import spinal.core._
import spinal.core.sim._
import spinal.lib._
import org.scalatest.funsuite.AnyFunSuite

class FreelistSpec extends AnyFunSuite {
  def mk = Freelist(physCount = 48, archCount = 16, popPorts = 2, pushPorts = 2)
  test("pops return distinct free ids (>= archCount)", VerilatorTest) {
    SimConfig.withVerilator.compile(mk).doSim { dut =>
      dut.clockDomain.forkStimulus(10)
      dut.io.flush #= false; dut.io.pop.foreach(_.take #= false); dut.io.push.foreach(_.valid #= false)
      // allow init to fill
      dut.clockDomain.waitSampling(60)
      assert(dut.io.popReady.toBoolean, "should have free ids after init")
      val a = dut.io.pop(0).id.toInt; val b = dut.io.pop(1).id.toInt
      assert(a >= 16 && b >= 16 && a != b, s"distinct free ids >=16: a=$a b=$b")
      dut.io.pop(0).take #= true; dut.io.pop(1).take #= true
      dut.clockDomain.waitSampling(); dut.io.pop.foreach(_.take #= false); sleep(1)
      val c = dut.io.pop(0).id.toInt
      assert(c != a && c != b, s"next pop distinct from consumed: c=$c")
    }
  }
  test("push returns an id to the pool", VerilatorTest) {
    SimConfig.withVerilator.compile(mk).doSim { dut =>
      dut.clockDomain.forkStimulus(10)
      dut.io.flush #= false; dut.io.pop.foreach(_.take #= false); dut.io.push.foreach(_.valid #= false)
      dut.clockDomain.waitSampling(60)
      // drain a few, then push id 5 (an "old" arch mapping being freed)
      dut.io.push(0).valid #= true; dut.io.push(0).payload #= 5
      dut.clockDomain.waitSampling(); dut.io.push(0).valid #= false; dut.clockDomain.waitSampling()
      // 5 must eventually be poppable (it's now free); pop until we see it or exhaust a bound
      var seen = false; var i = 0
      while (!seen && i < 40) {
        if (dut.io.pop(0).id.toInt == 5) seen = true
        else { dut.io.pop(0).take #= true; dut.clockDomain.waitSampling(); dut.io.pop(0).take #= false; sleep(1) }
        i += 1
      }
      assert(seen, "pushed id 5 should become poppable")
    }
  }
}

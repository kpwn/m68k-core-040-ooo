# MOVEM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement MOVEM (multi-register load/store, `.W`/`.L`, control + `(An)+`/`-(An)`) via a `DecodeStage` micro-sequencer that emits 2 register-move load/store µops per cycle over multiple cycles — the core's first variable-length, multi-cycle-emitted instruction.

**Architecture:** A small FSM in `DecodeStage`. On a MOVEM packet it holds `fed`, latches the 16-bit mask + base + direction/size, and each cycle priority-extracts the lowest (or highest, for `-(An)`) **two** set mask bits and drives `pushProduced.uops(0..1)` (count 2, or 1 for the odd tail) with their load/store µops — driving the queue push directly, sidestepping the 3-µop crack budget. At mask-empty it emits one final `An := base ± count*size` µop (for `(An)+`/`-(An)`), then resumes. `pipeFlush` aborts.

**Tech Stack:** SpinalHDL 1.14.1 / Scala 2.13 / sbt at `~/sbt/bin/sbt` (NOT on PATH) / Verilator / Vivado 2025.2 (`xcku5p-ffvb676-2-e`, OOC 4 ns). Lock-step vs `m68k040.oracle.Musashi`.

**Working dir:** isolated git worktree on `feat/movem` off current `master` (`474f40f`).

**Discipline (HARD):** `~/sbt/bin/sbt`. NEVER Verilator+Vivado concurrent. NEVER the whole `ExecuteLockStepSpec` — `-z` subsets, each its OWN `JAVA_OPTS=-Xmx10g timeout 1000 ~/sbt/bin/sbt …` JVM, never batched, output to files. After ANY decode/predecode change re-run `OperationDecoderSpec` + `PredecodeWordSpec` (VerilatorTest, OUTSIDE fastTest — they rot silently). The synth gate (≥200) is the final step.

**Templates to study first:** `DecodeStage.scala` — the `pushProduced`/`fed.ready`/`pipeFlush` emission loop (the MOVEM FSM overrides `pushProduced` + holds `fed.ready`); `MicroOpAssembler.scala` — the `ldUop`/`stUop` load/store µop shapes (memOp LOAD/STORE, srcA=base/baseValid, disp) + the predec/postinc `eaAuto`/An-update; `EaDecoder` for the EA base/disp of the control modes; `PredecodeWord.scala`/`PredecodeRef.scala` for 2-word framing.

## Task 1: MOVEM recognition + the DecodeStage micro-sequencer FSM

**Files:** `OperationDecoder.scala`, `DecodeStage.scala`, `MicroOpAssembler.scala`, NEW `MovemDecodeSpec.scala`.

- [ ] **Step 1: Recognize MOVEM in OperationDecoder**

In `OperationDecoder.scala` line-4 (`is(0x4)`), detect `opword(15 downto 6)` matching
`0100 1 d 001 s` i.e. `opword(15 downto 12)===0x4 && opword(11)===1 && opword(8 downto 7)===B"00" && opword(6 downto 6)`...
precisely: MOVEM = bits `15:12=0100`, `11=1`, `10=d`, `9:7=001`, `6=s`. So
`isMovem = (line===0x4) && opword(11) && (opword(9 downto 7) === B"001")`. Expose to the FSM
a `movem` marker + `dir = opword(10)`, `sizeLong = opword(6)`, and the EA (mmmrrr) via the
existing EaDecoder (control/`(An)+`/`-(An)` base+disp). Keep MOVEM **non-illegal** (the FSM
in DecodeStage produces the µops; OperationDecoder just classifies it, like EXG's placeholder).
The 16-bit mask is the extension word `fed.payload.packets(0).words(1)`.

- [ ] **Step 2: A single-register-move µop builder in MicroOpAssembler**

Add a helper (reuse the `ldUop`/`stUop` field set) that builds one MOVEM move µop:
```scala
// One MOVEM element: load [base+disp] -> reg (dir=load, sign-extend .W to 32), or
// store reg -> [base+disp] (dir=store). Plain LOAD/STORE µop, no flags, firstOfInstr param.
def movemMoveUop(reg: UInt, base: UInt, baseValid: Bool, disp: Bits, sizeLong: Bool,
                 isLoad: Bool, first: Bool): DecodedUop = { … memOp := Mux(isLoad,LOAD,STORE);
    size := Mux(sizeLong, Size.LONG, Size.WORD); srcAReg:=base; srcAValid:=baseValid;
    // load: dstReg=reg, dstValid; .W sign-extends in the LS writeback (size=WORD path).
    // store: srcBReg=reg (the stored data), no int dst. disp carries the element offset. … }
```
(Match the exact field set of the existing `ldUop`/`stUop`; the disp is the running element
offset the FSM computes. `.W` load sign-extend: confirm the LS load-result path sign-extends
for `Size.WORD` into a full reg — if MOVEM.W must always sign-extend regardless of the normal
.W partial-merge, set the load µop to write the full 32 (a MOVEM-load marker or reuse the
sign-extend path); the lock-step `.W` case is the arbiter.)

- [ ] **Step 3: The FSM in DecodeStage**

Add to `DecodeStage.logic` an FSM that overrides the `pushProduced` source when active:
```scala
val movemActive = RegInit(False)
val movemMask   = Reg(Bits(16 bits))     // remaining registers (already in the right bit order)
val movemBase   = Reg(UInt(32 bits))     // running address base (control: An or folded abs/PC)
val movemOff    = Reg(SInt(32 bits))     // running element offset (control/postinc); predec uses -
val movemAn     = Reg(UInt(5 bits))      // the An for (An)+/-(An) final update (0=none)
val movemDir/ movemSizeLong / movemRev (predec) / movemCount latches …
```
- **Enter:** when `!movemActive && fed.valid && <MOVEM at slot0>`: latch mask (REVERSED for
  `-(An)`: see below), base/dir/size/An, set `movemActive`, count the mask popcount for the
  final An. Hold `fed.ready := False`.
- **Bit order:** for control/`(An)+` the move order is ascending register (D0..A7) = ascending
  address; for `-(An)` the 68k mask is reversed — store A7..D0 to descending addresses. Pick
  the **lowest 2 set bits** (forward) or **highest 2** (reverse) each cycle via a priority
  encoder; map bit→reg (forward: bit i → reg i (D0..D7,A0..A7); reverse: bit i → reg 15−i).
- **Emit (each cycle):** drive `pushProduced.valid := True`, `uops(0/1)` = `movemMoveUop` for
  the (≤2) extracted bits with addresses `base + runningOffset` and `+ size` for the second,
  `count` = number extracted this cycle (2, or 1 for the odd tail). Predec: addresses step
  DOWN by size. Advance `movemOff`/running base by (extracted × size); clear the extracted
  mask bits. **Only advance when `pushProduced.ready`** (queue accepted) — else hold (stall).
- **Finish:** when `movemMask === 0`: if `(An)+`/`-(An)`, the NEXT emit cycle drives ONE final
  µop `An := movemAn ± count*size` (a plain ADD, `dstReg=An`), then `fed.ready := True` +
  `movemActive := False`. Control modes: skip the final µop, just release `fed`.
- **Flush:** `when(pipeFlush){ movemActive := False }`.
- Gate the normal `a0`/stash push source to NOT fire while `movemActive` (the FSM owns
  `pushProduced`).

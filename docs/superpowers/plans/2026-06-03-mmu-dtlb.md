# MMU / DTLB / Hardware Table-Walker (D-side, slice 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans. Checkbox steps. The synth gate (final task) is MANDATORY (≥250 MHz).

**Goal:** Replace the identity `DTranslationService` stub with a real 68040 D-side MMU — a banked set-associative DTLB + a hardware 3-level table-walker (4 KB pages) that fills the TLB on a miss, validates permissions, and (per spec) defers U/M descriptor writes to commit. Faults are *detected and flagged* (delivery is the later exception slice). Translate-at-execute; a TLB miss is a bounded variable-latency event on the existing LS stall path. Hold the full-core synth ≥250 MHz.

**Architecture:** A `Tlb` component (banked set-assoc, parametric) + a `TableWalker` FSM behind a new `DtlbPlugin` that implements `DTranslationService`, replacing `DIdentityTranslationPlugin`. The LS EU already requests translation at execute; on a TLB hit it gets PPN/perms in 1 cycle, on a miss the walker runs (multi-cycle, the LS EU stalls via the existing `loadBusy`/single-outstanding path), fills the TLB, resolves. The walk sets descriptor U (and M on a write) — queued and drained at commit (reuse the SQ commit-drain discipline). MMU-disabled = identity passthrough (existing behavior, default for all current tests).

**Tech Stack:** SpinalHDL 1.14.1 / sbt `~/sbt/bin/sbt` (NOT on PATH) / Verilator / Vivado. Reference: `mmu/DIdentityTranslationPlugin.scala` + `services/Services.scala` (`DTranslationService`, `TranslationReq/Rsp`, `CacheMode`), `cache/IcachePlugin.scala` (AXI read pattern for the walker), `execute/LsEuPlugin.scala` (translate-at-execute consumer + the single-outstanding stall), `ls/BehavioralMem.scala` (read/write AXI mem for the page table), `oracle/Musashi.scala` (check whether it exposes 040-MMU config for lock-step). Spec: `docs/superpowers/specs/2026-06-03-mmu-tlb-walker-design.md`.

**Branch:** `feat/mmu-dtlb` (created; spec committed). **MMU-disabled must be a pure identity passthrough so every existing test/lock-step is unchanged.**

### Task 1: `Tlb` component (banked set-associative ATC)
**Files:** Create `src/main/scala/m68k040/mmu/Tlb.scala`; Test `src/test/scala/m68k040/mmu/TlbSpec.scala`.
Parametric `Tlb(entries=32, ways=4, banks=2)`. Entry `{valid, vpnTag, ppn, writeProt, supervisor, cacheMode}`. `bank = vpn(bankBits)`, set within bank, way-compare tag → combinational/1-cycle hit + `{ppn, perms, cacheMode}`. Ports: `lookup(vpn) → hit/entry`; `fill(vpn, entry)`; `invalidateAll` (clear valid — RegInit'd). Shallow per-bank way-mux (FPGA-friendly, no deep CAM).
- [ ] failing test (fill an entry → lookup hits with correct ppn/perms; miss on a different vpn; invalidateAll clears) → FAIL → implement → PASS ×2 → commit `mmu: banked set-associative TLB component`.

### Task 2: `TableWalker` FSM (68040 3-level walk)
**Files:** Create `src/main/scala/m68k040/mmu/TableWalker.scala`, `src/main/scala/m68k040/mmu/MmuTypes.scala` (descriptor format); Test `src/test/scala/m68k040/mmu/TableWalkerSpec.scala`.
FSM: given `{vpn, rootPtr, isWrite, isSuper}`, issue 3 dependent AXI reads — root[VA root idx] → pointer[VA ptr idx] → page[VA page idx] — decode the 68040 descriptor (resident/type bits, PPN, write-protect, U/M); produce `{ppn, writeProt, supervisor, cacheMode, fault, faultReason}` + the U/M descriptor-write requests `{descAddr, setU, setM}`. 4 KB pages: VA = `[root(7) | ptr(7) | page(6) | offset(12)]` (confirm exact 040 field widths/descriptor layout against the m68040 PRM; the agent decodes the real format). Dedicated AXI read port (or shared with D-cache — pick one, document). Bounded multi-cycle.
- [ ] failing test (hand-build a 3-level table in `BehavioralMem`; walk a VPN → correct non-identity PPN + perms; a non-resident descriptor → fault; a write-protected page + isWrite → fault) → FAIL → implement → PASS ×2 → commit `mmu: 68040 hardware 3-level table walker`.

### Task 3: `DtlbPlugin` (TLB + walker behind DTranslationService) + LS integration
**Files:** Create `src/main/scala/m68k040/mmu/DtlbPlugin.scala`; Modify `top/FullCoreSynth.scala` + the test Duts to host `DtlbPlugin` instead of `DIdentityTranslationPlugin`; Test `src/test/scala/m68k040/mmu/DtlbSpec.scala`.
`DtlbPlugin extends DTranslationService`: a `mmuEnable` + `rootPtr` register (test-poked; MOVEC decode deferred). When disabled → identity passthrough (`ppn=vpn`, cacheable, no fault) — existing behavior. When enabled: lookup the `Tlb`; hit → 1-cycle response; miss → run `TableWalker` (the `DTranslationService.rsp` signals not-ready/late so the LS EU stalls on the existing `loadBusy`/single-outstanding path), fill the TLB, then respond. Fault → `rsp.fault` + reason (flagged, NOT delivered). Speculative TLB fill is allowed.
- [ ] failing test (full DUT: enable MMU + a page table in memory; a load to a VA → TLB miss → walk → fill → correct PA data; second load → TLB hit; disabled → identity) → FAIL → implement → PASS ×2 → commit `mmu: DtlbPlugin (TLB+walker behind DTranslationService) + LS integration`.

### Task 4: U/M descriptor-write queue (deferred to commit)
**Files:** Create `src/main/scala/m68k040/mmu/UmWriteQueue.scala` (or fold into the SQ); Modify `DtlbPlugin`/ROB wiring; Test `src/test/scala/m68k040/mmu/UmWriteSpec.scala`.
A small queue of `{descAddr, newByte}` produced by a walk (set U; set M on a write access), tagged with the triggering robId. Entries are speculative until that instruction commits; on commit → drain (RMW the descriptor byte to memory via the D-side write path); on flush → discard. Mirrors the SQ commit-drain/flush discipline (RegInit, drain-ack).
- [ ] failing test (a walk for a write access queues an M-bit write; commit drains it → descriptor byte updated in `BehavioralMem`; flush discards it → memory unchanged) → FAIL → implement → PASS ×2 → commit `mmu: U/M descriptor-write queue (drained at commit, discarded on flush)`.

# Trap-family (TRAP #n, TRAPV) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development / executing-plans. Checkbox steps. Final task = HONEST MMU-live synth gate (≥250, mmuEnable live, both TLBs+walkers inferred).

**Goal:** Decode + deliver TRAP #n (unconditional, vector 32+n) and TRAPV (vector 7, trap-if-V) via the existing format-$0 exception machinery, lock-stepped vs Musashi.

**Architecture:** TRAP #n is a decode-time unconditional faulted µop (vector 32+n). TRAPV is an execute-time conditional fault: a trap-check µop reads NZVC(V) and, if V, drives a fault-completion (like the branch/LS fault completions) that marks the ROB entry faulted (vector 7). Both deliver via the merged commit-side format-$0 FSM. Stacked PC = the µop's nextPc (TRAP/TRAPV are not restartable).

**Tech Stack:** SpinalHDL 1.14.1 / sbt `~/sbt/bin/sbt` / Verilator / Vivado. Reference: `decode/OperationDecoder.scala`+`MicroOpAssembler.scala` (decode → DecodedUop faulted/faultVector), `rob/RobPlugin.scala` (fault capture {faulted,vectorNum,faultPc}; the branch/LS fault-completion pattern for execute-time set), `exception/ExceptionUnit.scala` (format-$0 delivery + RTE — unchanged), `execute/BranchEuPlugin.scala` (NZVC read + condition eval — the model for TRAPV's V read), `lockstep/ExecuteLockStepSpec.scala`. Spec: `docs/superpowers/specs/2026-06-05-traps-design.md`.

**Branch:** `feat/traps` (created; spec committed).

# CAS / CAS2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement CAS `.B/.W/.L` and CAS2 `.W/.L` (68020+ atomic compare-and-swap), byte-identical vs Musashi, cracked through the microcode-v2 engine.

**Architecture:** Atomicity is free (in-order single-pipe LS + store-queue — no bus-lock). The microcode-v2 engine cracks CAS into load→CASCMP→store and CAS2 into load×2→CAS2CMP→store×2. The engine has no conditional store, so we ALWAYS store the mux'd value (Du on match, the loaded value back on mismatch = architecturally a no-op for RAM) — a documented, reversible simplification. CMP flags reuse the existing AluDatapath CMP path.

**Tech Stack:** SpinalHDL 1.14.1 / Scala 2.13 / Verilator / Vivado 2025.2 (xcku5p-ffvb676-2-e). sbt at `~/sbt/bin/sbt`. Oracle = Musashi (`tools/musashi/`).
